# Changelog

All notable changes to UI Reference Replication are documented here.

## [4.0.0] - 2026-11-06

### Community Edition scope reset

- Restricted the free Community Edition to one fidelity target: Reference-Faithful.
- Removed the creative reinterpretation workflow from the public package.
- Removed advanced creative-direction, anti-AI-slop, structured Figma intelligence, motion engineering, benchmark, agent compatibility certification, and extended automated QA/reporting modules from the current Community Edition.
- Retained new builds, existing UI redesigns, hybrid work, visual inspection, basic design tokens/components, responsive implementation, accessibility guidance, screenshot capture, and pixel-difference diagnostics.
- Simplified installation, documentation, package scripts, and repository validation around the focused free workflow.
- Kept the MIT license for the code and documentation that remain in this repository.

The repository's prior commits and published MIT-licensed releases remain part of its public history. This release defines the current Community Edition scope; it does not retroactively revoke rights granted under earlier MIT releases.
